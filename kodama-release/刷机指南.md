# Google Kodama (sku16) LineageOS 23.2 刷机包说明

> 适用机型：Google Kodama sku16（MT8183 平板，与 Lenovo IdeaPad Duet 同型）
> 系统：LineageOS 23.2（Android 16），内核 Linux 6.18.28
> 镜像构建日期：2026-11-08

## 一、包内容

GitHub 发布页只提供 `lineage-23.2-kukui-20261108.zip`。`lineage-23.2-kukui-20261108.img` 已包含在 zip 内，不需要单独下载；`kodama-release/` 下的脚本和 IDC 在本仓库的 `kodama-release/` 目录。

> 20261108 版本的 U 盘 userdata 已清理，仅保留 Kodama 触摸 IDC。U 盘启动时触摸正常；安装到 eMMC 后安装器会格式化 eMMC userdata，仍需执行第五节的 `fix-touch.sh`。

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `lineage-23.2-kukui-20261108.zip` | 约 1.1 GB | 刷机镜像压缩包，Rufus / BalenaEtcher 可直接写入 U 盘 |
| `lineage-23.2-kukui-20261108.img` | 约 11.8 GB | zip 解压后的 U 盘镜像；发布页不单独提供，Linux 可用 dd 写入 |
| `kodama-release/idc/` | — | Kodama 触摸屏 IDC 配置（刷机后修正触摸方向用） |
| `kodama-release/fix-touch.sh` | — | 通过无线 adb 一键写入触摸 IDC |
| `kodama-release/SHA256SUMS.txt` | — | 全部文件校验和 |

镜像本身是「U 盘安装盘」：写入 U 盘后从平板 U 盘启动，使用系统内置的
**Install to eMMC** 安装器把系统写入平板内部存储（eMMC）。

## 二、刷机前的准备

- 一个 **16 GiB 以上**的 U 盘（镜像约 10.9 GiB）。写入会清空整个 U 盘，请先备份。
- 平板需要处于**开发者模式**：
  - 关机状态下同时按住**电源键 + 音量加 + 音量减**约 10 秒进入恢复界面，
    按 **Ctrl+D** 开启开发者模式（首次开启会清除本机数据）。
  - 若设备已是开发者模式，开机时开发者屏幕按 **Ctrl+U** 即可从 U 盘启动。
  - 不同固件版本的按键组合可能略有差异，以设备的官方说明为准。
- 本包只在 **kodama-sku16** 上测试过。其他 Kodama SKU 的屏幕/触摸可能不同，请谨慎。

## 三、写入 U 盘

### Windows（推荐）

1. 下载 Rufus（https://rufus.ie）或 BalenaEtcher（https://etcher.balena.io）。
2. 直接选择 `lineage-23.2-kukui-20261108.zip`，**无需解压**。
3. 若 Rufus 询问写入方式，选择 **DD 模式**。
4. 开始写入，等待完成。

### Linux

```sh
# 先 lsblk 确认 U 盘设备名；把 /dev/sdX 换成整个 U 盘（不是分区），选错盘会毁掉该盘数据！
unzip -p lineage-23.2-kukui-20261108.zip | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
```

## 四、启动并安装到 eMMC

1. U 盘插入平板并开机，在开发者屏幕按 **Ctrl+U** 从 U 盘启动 Android。
2. 首次启动进入设置向导，按提示完成。Wi-Fi 可能要等 1~2 分钟才出现，属正常现象。
3. 打开应用 **Install to eMMC**：
   - 选择 **Android only**（仅 Android）。
   - 按钮只有在「系统正运行于 U 盘、且检测到内部 eMMC」时才可点击。
   - 确认后等待，直到界面提示可以拔掉 U 盘。安装器不会自动重启。
4. 拔掉 U 盘，重新开机。之后即直接从 eMMC 启动。

补充说明：

- **Android and Linux**（Android + Linux）是给 postmarketOS 分区布局用的双系统方案，
  Kodama 请勿选择。
- **Update system**（更新系统）只替换 super / 内核 / 启动菜单，不清除用户数据。
- 安装器界面随系统语言显示，含中英文。
- **不要把 U 盘镜像直接 dd 到 eMMC**：U 盘分区表和 eMMC 分区表不同，直接 dd 会损坏设备。
  请使用内置安装器。
- **Android only 会清空 eMMC 上的原有数据**（包括其他系统），操作前请备份。

## 五、安装后的第一次设置

### 1. 修正触摸方向（必做）

本镜像的 vendor 分区未包含 Kodama 的触摸 IDC（构建时间早于该修复），
新刷机器的触摸方向可能不对。用无线 adb 写入一次即可：

1. 平板：设置 → 关于平板 → 连续点击「版本号」开启开发者选项；
   在开发者选项中开启**无线调试**，进入「使用配对码配对设备」，记下 IP、端口和配对码。
2. 电脑（在本目录执行）：

```sh
adb pair <平板IP>:<配对端口>     # 输入配对码
adb connect <平板IP>:<连接端口>
./fix-touch.sh
```

脚本会写入两个 IDC 文件并自动重启，重启后触摸方向恢复正常。

也可以手动操作：把 `idc/hid-over-i2c_04F3_2ABE.idc` 和
`idc/hid-over-i2c_04F3_2ABE_Stylus.idc` 以 root 身份复制到设备的
`/data/system/devices/idc/`（权限 644），重启即可。

### 2. 时间同步

本机**没有 RTC（实时时钟）**，每次开机时间先回到镜像构建时间。
保持「自动设置时间 / 时区」开启，确保网络可达 NTP 服务器，
联网后约半分钟自动校准。依赖 TLS 证书校验的应用请等时间校准完成后再使用。

### 3. Wi-Fi

新 userdata 的首次开机，Wi-Fi 可能要等 1~2 分钟才出现，期间系统会自动重载无线模块，
之后使用正常。

## 八、隐私与数据说明

- 本镜像为全新构建：userdata 分区是空文件系统，**不包含任何个人数据**、
  账号、网络配置或第三方应用。
- 「Android only」安装会格式化 eMMC 数据区。
- 收到文件后请校验完整性。只下载 zip 时用 `--ignore-missing`，未解压的 img 行会跳过；解压后可去掉该参数同时校验 img：

```sh
sha256sum -c --ignore-missing kodama-release/SHA256SUMS.txt
```
